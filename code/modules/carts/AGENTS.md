# Корзины

`@module/carts` владеет списком корзин покупателей.

- CartController загружает CartResultEntity через CartServiceInterface.getAll.
- Источник списка — административный GET /v1/carts; UI не вычисляет содержимое корзин и не загружает карточку каждой строки.
- Пагинации кнопками и query page нет. Сейчас загружается одна порция API (по умолчанию 50 корзин). Дозагрузка требует отдельного контракта nextToken; offset в токен не преобразовывать.
- Table из @sellgar/kit/table использует внешний scroll, виртуализацию и loading из useRevalidate().inProcess. Модуль не импортирует токен собственного маршрута.
- Владелец отображается как ownerUuid из API: нельзя выдавать его за имя пользователя или определять тип сессии по UUID.
- Количество означает число позиций, без суммирования quantity. Состояние определяется closedAt. Даты форматируются для ru-RU.
- Клик строки открывает CartReviewRoute с UUID корзины в общем Drawer. Просмотр принадлежит @frame/cart-review; закрытие не вызывает ручную перезагрузку списка.
- Изменение состава и административная realtime-подписка пока не подключены.

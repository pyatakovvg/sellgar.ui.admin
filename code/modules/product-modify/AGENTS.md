# @module/product-modify

Форма создания и редактирования общих данных товара. Шаблон выбирается только при создании.
Маршруты: `/products/create`, `/products/:uuid/edit`.

- Варианты не входят в форму и не сохраняются ее action.
- Просмотр товара и таблица вариантов принадлежат `@module/product-review`.
- Создание, просмотр и редактирование одного варианта принадлежат `@frame/product-variant-*`.
- Общие поля свойств, их валидация и преобразование принадлежат `@library/product-form`.
- Не сбрасывать пользовательский ввод при сокетных обновлениях. Сохранение проверяет исходную version.
- HTTP/multipart принадлежат доменному gateway; события Product остаются полными и совместимыми.

# Просмотр корзины

`@frame/cart-review` — модуль просмотра корзины в общем application Drawer.

- CartReviewRoute принимает uuid корзины. Loader CartReviewController вызывает CartServiceInterface.findByUuid и возвращает CartEntity без локального дубликата либо null при 404. View показывает отсутствие корзины внутри фрейма с доступным закрытием; остальные ошибки передаются framework boundary.
- MainLayout содержит только FrameLayout, заголовок и закрытие Drawer. View показывает сведения, состав и сумму товаров. Команд изменения состава нет.
- Items использует @sellgar/kit/table: sm, secondary, внешний scroll, виртуализация и loading из useRevalidate().inProcess своего runtime.
- Название, исполнение, артикул, уточнения, доступное количество и сообщения о недоступности берутся из CartItemEntity. Удалённая или скрытая позиция остаётся видимой.
- Количество, цена и сумма показываются отдельно. Денежные строки форматируются без Number и без пересчёта итогов на фронте. null означает отсутствие рассчитанной суммы, а не ноль.
- Владелец показан UUID из API; тип сессии и имя пользователя по нему не вычисляются.
- Открытие и закрытие фрейма не перезагружают список корзин вручную. Пагинации и административного realtime здесь нет.

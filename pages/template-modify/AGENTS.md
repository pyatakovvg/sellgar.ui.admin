# AGENTS

## Зона ответственности

`@page/template-modify` владеет route-level формой шаблона товара.

## Правила

- Шаблон сохраняется как единый агрегат типа товара.
- `productFields` задают структуру товара, `variantFields` — структуру каждого его варианта.
- Порядок строк формы является `sortOrder`.
- Контроллер передаёт input в доменный сервис, транспортный DTO формирует gateway.

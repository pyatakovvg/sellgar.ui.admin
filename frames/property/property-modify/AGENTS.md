# AGENTS

`@frame/property-modify` владеет drawer создания и редактирования свойства.

- Пакет расположен в `frames/property/property-modify`; просмотр принадлежит соседнему `@frame/property-review`.
- `PropertyCreateRoute` открывает создание, `PropertyModifyRoute` — редактирование; `code` берётся из `args.params`.
- Код, тип и размерность неизменяемы после создания. Не добавлять удаление сохранённых опций.
- Controller разделяет create/update и управляет переходами; `PropertySaveService` последовательно сохраняет опции с версией из каждого ответа.
- Каждый успешный ответ применяется через `updateEntity`; повтор сохранения определяет существующие опции по последнему ответу сервиса.
- `insertEntity` добавляет созданное свойство в загруженный список. Переход в просмотр выполняется без ревалидации списка.
- Factory формирует начальные значения, Serializer переводит форму в Input локального сервиса; визуальный ICON сериализуется как TEXT с `textDisplay: ICON`.
- `useBlocker` защищает несохранённую форму; разрешение перехода выдаётся только после полного успешного сохранения.
- Опции и вложенные визуальные данные имеют отдельные компоненты и CSS Modules; перестановка работает через `useFieldArray.move`.

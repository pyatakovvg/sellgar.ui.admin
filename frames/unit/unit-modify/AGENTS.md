# AGENTS

`@frame/unit-modify` владеет drawer создания и редактирования единицы измерения.

- Пакет расположен в `frames/unit/unit-modify`; просмотр принадлежит соседнему `@frame/unit-review`.
- Создание открывается по `UnitCreateRoute`, редактирование — по `UnitModifyRoute`.
- Параметр `code` приходит через `args.params`; тип выводится из route token.
- Controller разделяет сценарии создания и обновления; локальный Mapper формирует доменные Input.
- Форма содержит код, наименование, обозначение и необязательное многострочное описание; код при редактировании неизменяемый.
- `useBlocker` защищает несохранённую форму. `NavigationBlockerServiceInterface.allow` разрешает только переход после успешного сохранения.
- Ответ сервиса применяется через `insertEntity`/`updateEntity`; переход в просмотр выполняется без ревалидации списка.
- Компоненты отдельных полей принадлежат `Fields` и импортируются через локальные фасады.

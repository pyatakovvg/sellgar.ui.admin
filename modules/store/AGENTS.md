# AGENTS

## Зона ответственности

`@module/store` владеет route списка складских позиций `/store`.

## Правила

- Loader списка складских позиций, table и header держать здесь.
- Создание открывает StoreCreateRoute; одиночный клик открывает StoreReviewRoute. Из просмотра редактирование открывается по StoreModifyRoute.
- Все три уровня списка используют новый `Table` из `@sellgar/kit/table`.
- Явные width/minWidth/maxWidth в декларациях колонок Склада задаются как `var(--numbers-X)` для проверки токенного API из ТЗ; числовой API кита также поддерживается.
- В основном списке resize явно включён у pin «Товар» и «Витрина». Статус24 и все колонки вложенных таблиц сохраняют resizable=false по умолчанию.
- Три уровня образуют единую горизонтальную поверхность с одним kit Scrollbar у основной таблицы. Вложенные уровни передают необходимую ширину родителю и прокручиваются вместе с ним.
- Все уровни используют внешний вертикальный scroll, встроенную идентификацию строк по объектам и render scopes. Основной хедер закрепляется, вложенные хедеры не закрепляются. Раскрытие принадлежит новому runtime и учитывается в измеряемой геометрии строк; одиночный и двойной клик разделены.
- Одиночный клик по товару открывает просмотр, двойной клик по товару или варианту раскрывает вложенную таблицу. Стрелки раскрытия не используются. Основная таблица использует `surface="standalone"` и `size="md"`; вложенные таблицы — `surface="embedded"` и минимальный `size="sm"`.
- Данные store list приходят из `store_srv` через admin gateway. Не тянуть
  price/currency/store данные из product domain.
- Не оборачивать эту страницу в sticky layout без redesign route-level scroll contract.

- Таблица раскрывает товар → варианты → учётные записи. Артикул, уточнения и остаток относятся к записи; inventory action получает `recordUuid`.
- Вложенные уровни не добавляют левый отступ и внешнюю рамку, включая границы обёрток. Общая внешняя рамка принадлежит только основной standalone-таблице.

- В основном списке для проверки pin закреплены статус и «Товар» слева,
  «Витрина» справа; reserve=50 логических numbers применяется по умолчанию Table; consumer не задаёт override.
  Auto «Магазин» остаётся в центре. Вложенные таблицы не закрепляют колонки.

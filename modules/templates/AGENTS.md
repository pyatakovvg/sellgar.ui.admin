# AGENTS

## Зона ответственности

`@module/templates` владеет списком шаблонов товара.

## Правила

- Шаблон в UI соответствует агрегату типа товара.
- Создание и редактирование выполняется на route-level странице `@module/template-modify`.
- Primary action строки — открытие шаблона.
- Список использует `@sellgar/kit/table`: внешний scroll owner, виртуализация, `uuid`, `lg`.
- Название — auto с минимумом 280, счётчики имеют ширину 176, resize выключен. Реактивные ячейки
  `Name` и `ProductCount` получают сущность через `Cell.render`.
